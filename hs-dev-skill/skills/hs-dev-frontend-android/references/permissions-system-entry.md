# Android 权限与系统入口

只检查本次涉及的授权或系统入口。平台声明、组件安全和生命周期与 Android 框架技能协同处理，不扩大权限或产品能力。

- [ ] **授权时机与结果**：核实实际 API、系统版本和 targetSdk 对权限行为的影响；在用户执行相关功能且可理解用途时按既定流程申请。覆盖适用的允许、拒绝、不可再次请求和撤销场景，不强迫重复弹窗；解释、设置跳转和降级方式由产品契约决定，缺失时返回当前过程。
- [ ] **请求后状态**：检查授权结果返回、设置页返回或权限变化后的界面与实际能力一致，不因过期状态继续显示成功或重复操作；明确系统对话框及设置页不由应用控制的边界。
- [ ] **外部入口**：对实际使用的通知、深链接、分享或选择器核对输入、目标与反馈。按需检查冷启动、已有页面及需认证状态；目标失效、输入不支持或授权不足时不静默丢弃，也不绕过访问控制。
- [ ] **取消与失败**：区分用户取消、能力不可用、访问撤销和操作失败，按契约恢复界面并反馈，不把打开系统界面当作业务成功。涉及临时内容访问时核对实际使用时限，持久授权与框架专项协同检查。
- [ ] **验证**：记录受影响入口的操作、预期、初始授权、启动/登录状态、设备与系统版本、实际返回和界面结果。覆盖相关拒绝、取消和失败路径；模拟器不支持或未执行的场景标记未验证，不以正常入口成功代替异常验证。
