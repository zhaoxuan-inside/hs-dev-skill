# Android 导航与布局

只选择本次涉及的条目，沿用已确认交互、设计系统和设备支持范围，不扩大导航架构或设备矩阵。

- [ ] **返回与导航**：核对页面、弹层、输入法及未保存内容涉及的返回顺序，遵循既有导航和产品契约。涉及手势或预测性返回时核对实际系统、SDK 和工具包支持，不用自定义拦截破坏既定路径。
- [ ] **窗口与遮挡**：检查支持的窗口尺寸、方向、系统栏和输入法状态下的内容与操作可用性；关注边到边布局、安全区域、焦点字段和关键操作遮挡。按需覆盖分屏或折叠姿态，不以设备类别替代实际窗口约束。
- [ ] **文字与内容**：按需检查大字体、显示缩放、长文本和本地化下的截断、重叠、滚动与操作可达性，不以缩小字体或隐藏必要内容替代适配。
- [ ] **辅助技术与输入**：核对受影响控件的标签、角色、状态、触控区域与焦点顺序；按需要用 TalkBack 验证阅读、操作和动态反馈。项目支持键盘等输入时检查对应行为，不默认所有设备有相同输入能力。
- [ ] **取证**：记录代表性场景的尺寸、方向、系统栏、输入法、字体设置及操作结果。截图不能证明返回顺序、读屏或焦点行为；无法运行时标记未验证。生命周期和状态恢复与框架专项协同检查。
