# 完整包安装更新

明确授权后安装当前完整包，校验、替换、失败恢复。遵守[主入口](../../SKILL.md)及[专属协议](../../share/support/update.md)，不改变业务验收权限。

## 执行清单

- [ ] **明确请求与授权**：区分检查版本、评估安装和实际更新。只读检查不替换文件；用户已明确授权的目标和动作直接沿用，不重复确认。缺少源包或目标且无法从上下文唯一确定时先核实，不猜安装位置。目录写入权限仍按宿主要求处理。
- [ ] **核实源包**：定位本次提供的当前完整包，检查内部包校验结果及版本来源；不能仅凭目录名或版本字符串认定有效。此入口不自动下载、寻找最新发布、解析旧版或迁移格式；源包不可用时报告缺失条件，不以零散文件拼装代替完整包。
- [ ] **核实目标与替换范围**：解析实际路径，确认源与目标独立，不互为父子目录；按协议排除工作副本和符号链接，不能借路径解析绕过限制。检查目标是否为预期安装及是否含本地定制、工程数据或其他未归属内容。整目录替换会移除目标中未包含的文件，不是合并升级；存在不明内容或超出授权范围时先解决，不直接覆盖。
- [ ] **执行安装**：通过现有 `install --source <完整包目录> --target <安装目录>` 调用，让底层完成暂存校验、旧目标备份、替换及安装后包校验。使用已核实的安装根调用 CLI，不从待替换目录运行长任务；避免和其他安装或目标写入并发。不得改用手工复制、删除旧目录或直接调用底层函数绕过入口。
- [ ] **核验结果或失败状态**：成功后核对实际目标、包校验及版本，按需要执行不改工程的最小启动/帮助检查；安装校验通过不证明所有功能可用。失败时保留原始错误，核实目标是否存在且与更新前基线一致；异常处理代码存在不等于已成功恢复。旧目标不存在时说明失败后的实际状态，不宣称已恢复旧版本。恢复不明或校验失败时停止，不继续覆盖或自动扩大清理。
- [ ] **交付并结束**：报告源包与目标、版本、实际替换范围、验证及未验证项、失败后的目标状态。安装不改工程产物或验收记录，不自动修改 Agent 配置、同步其他目录、发布或执行数据迁移；需要其他动作时交回负责流程。

## 调用与恢复边界

使用 `python <已核实安装根>/hs-dev-skill/scripts/hs_dev.py install --source <完整包目录> --target <安装目录>`；具体参数以当前 CLI 帮助为准。`--root` 不是安装目标，实际目标由 `--target` 指定；此入口名为 update，实际子命令是 install，不猜测不存在的 update 命令。

底层临时备份用于替换过程中的失败恢复，不能当作成功安装后的长期回退点。需要长期保留旧安装时，先在已授权范围内明确独立保存位置及验证方法；不承诺安装成功后仍可从临时目录回退。不得依靠安装器保留目标中的自定义文件。

## 结果要求

区分“仅检查、未执行、安装成功且已校验、安装失败且旧目标已核实恢复、安装失败且状态待核实”。记录命令退出结果和必要证据位置，不输出凭据或大量文件正文；简单更新直接回复，不强制新增报告。没有执行安装或结果验证不足时不宣称更新完成。
