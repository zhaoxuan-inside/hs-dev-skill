# Android 客户端框架

与 [客户端框架基础](../hs-dev-framework-client-base/SKILL.md)配合使用，只补充 Android 平台的应用架构差异。页面视觉与交互由 [Android 前端特性](../hs-dev-frontend-android/SKILL.md)和[前端基础](../hs-dev-frontend-base/SKILL.md)负责；服务端结构由后端框架入口负责。

## Android 框架特性

- **应用组件与导航。** 依据现有 Android 技术栈组织 Activity、Service、Receiver、Provider 及导航职责；仅使用确有需要的组件，明确组件间 Intent/数据边界及生命周期责任。
- **进程和状态恢复。** 设计配置变更、后台回收、进程重建和任务栈恢复。短期界面状态与需持久保存的业务状态分开管理，不能把进程内存视为可靠存储。
- **并发与后台工作。** 根据任务是否需要延续、时限和系统调度约束选择前台或后台执行方式；对取消、重试、重复调度和设备重启后的行为作出决定。
- **平台 API 与权限。** 将定位、通知、媒体、文件等 Android API 放在明确适配层；权限申请、版本差异和授权撤销可由业务流程处理，不让平台检查散布于领域逻辑。
- **构建与发布。** 按目标 Android 版本、构建变体、签名和分发渠道管理配置；敏感签名材料不进入源代码或客户端包内的非必要资源。
- **技术沿用。** 尊重项目采用的 Kotlin/Java、Compose/View 和依赖注入方案；框架替换需由明确约束驱动，并说明迁移范围。

共通框架方法、活动资料选择和交付要求见[客户端框架基础](../hs-dev-framework-client-base/SKILL.md)；此处只保留本平台差异。

## 验证

### 执行清单

沿用 Base 和当前过程的任务范围；只检查本次涉及的平台机制，不将局部修改扩大为全应用审计。

- [ ] **核实工程基线**：从构建配置、依赖和 Manifest 确认相关模块、minSdk/targetSdk/compileSdk、Gradle/Android 插件版本、组件声明、权限及构建变体；只读取本次需要的部分。沿用实际技术栈，区分工程事实、产品要求和待验证假设。
- [ ] **选择平台检查项**：按下表选择本次涉及的生命周期、后台任务、平台能力、入口或打包项。已有有效决定直接复用；不适用项说明理由，不为清单额外增加组件、权限或基础设施。
- [ ] **核对机制约束**：涉及系统行为或兼容性决定时，核对所用库版本及目标设备系统、targetSdk 对应的 Android 官方契约，记录来源与适用条件。后台工作方式应根据持续性、调度时机、用户可见性、取消和恢复要求选择，不能仅凭任务耗时选型。跨平台项目同时核对插件与原生边界，不默认改为原生实现。
- [ ] **实施或验证**：在授权范围内执行适用检查，记录操作、预期结果、实际结果、设备/API 级别、构建变体及证据。纯设计任务给出验证计划与尚未证实的假设，不把计划当作通过。依赖的产品行为未确定时返回当前过程，不自行定义恢复或降级行为。
- [ ] **交付**：逐项给出 `对象／决定与适用条件／状态／证据／未决项`，状态使用“通过、未通过、不适用、未验证”。说明模拟器与真实设备覆盖差异、未验证的平台行为及影响；不以专业自检代替当前过程的确认。

### 场景与证据

只执行本次受影响的场景；设备或环境不可用时标记未验证，不能用静态审阅冒充运行结果。

| 涉及项 | 检查与预期结果依据 |
|---|---|
| 配置变化与状态恢复 | 按实际配置变化重建界面，检查状态所有者、重复订阅和资源释放；另行验证进程终止后的重建及持久状态恢复，说明终止方式与恢复入口。配置变化、进程重建、任务移除和强行停止分别记录，不将其中一种结果外推为其他情形已通过 |
| 后台与并发任务 | 按采用机制检查取消、重复调度、重试上限及约束变化；只有任务明确要求时覆盖设备重启、低电量或其他系统限制。核对可观察结果与已确认的任务语义，注明测试条件，不能以调度成功证明任务最终完成 |
| 权限与系统能力 | 按适用版本验证允许、拒绝、撤销和能力不可用后的入口及结果，检查调用前后的状态处理；需要真机能力时明确模拟器证据的局限 |
| 组件、Intent 与导航入口 | 核对相关组件可见性、权限、Intent/深链接数据边界；对本次受影响的冷启动、已有任务及外部输入路径检查路由和状态，不默认将内部组件导出 |
| 构建与分发 | 构建或检查实际目标变体，核对合并后的 Manifest、配置和资源；涉及发布时再检查混淆、签名配置和包内敏感内容。构建成功只证明相应构建检查，不证明生命周期、权限或后台行为正确；签名凭据不写入报告，发布仍需对应授权 |
