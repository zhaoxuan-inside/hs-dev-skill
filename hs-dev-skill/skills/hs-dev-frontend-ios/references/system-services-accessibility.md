# iOS 系统服务与辅助功能

只选择本次涉及的系统能力或辅助功能，沿用项目控件和产品契约，不将所有平台特性列为必做。

- [ ] **授权与返回**：按实际能力和系统版本核对适用的授权状态，在功能上下文中请求；检查拒绝、受限、设置修改及返回应用后的界面是否与实际能力一致。降级、说明和设置入口依据产品契约，不反复强迫申请，不将系统面板打开视为业务成功。
- [ ] **系统入口与面板**：对实际使用的通用链接、通知、分享、文档选择器等核对输入、目标和反馈；按需覆盖冷启动、已有界面及认证状态。区分取消、目标失效、访问受限和能力不可用；组件声明、数据访问期限和生命周期由框架专项协同核验，不绕过访问控制或静默丢弃操作。
- [ ] **VoiceOver**：对受影响内容检查名称、角色、值、状态及分组；实际验证阅读顺序、核心操作、弹层焦点、关闭后的焦点恢复和动态反馈。静态标签存在不能证明完整操作可用，无法运行时说明缺失条件。
- [ ] **字体、外观与运动**：按目标要求检查动态字体及长文本下的截断、滚动与操作可达性；涉及系统外观时核对内容和状态可辨识性。相关动画应按既定可访问性要求处理减少动态效果，不以缩小文字或隐藏必要内容替代适配。
- [ ] **证据**：记录授权、登录、辅助功能及外观等相关初始条件，操作和实际结果；按能力说明模拟器与真机差异。未执行场景标记未验证，不以截图证明读屏、动态反馈或真实系统集成通过。
