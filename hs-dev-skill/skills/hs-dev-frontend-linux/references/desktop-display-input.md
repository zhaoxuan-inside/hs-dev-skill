# Linux 桌面、显示与输入

依据支持范围、变更和已知差异选择组合，不全量测试所有桌面、协议和输入方式。

- [ ] **桌面呈现**：核对目标桌面的字体、图标、菜单和窗口装饰，检查主题变化后内容、状态与操作仍可辨识；不假设 GNOME、KDE 或其他桌面行为一致，不为视觉统一强行替换系统行为。
- [ ] **显示与窗口**：在实际使用的后端检查相关缩放、窗口尺寸及恢复行为；涉及混合 DPI、分数缩放或多显示器时检查跨屏、弹层定位、内容截断与操作可达性。窗口架构和进程恢复交由框架专项协同。
- [ ] **键盘与文本输入**：检查受影响的导航、快捷键、焦点进入/退出和可见焦点；涉及文本输入时验证输入法组合、候选选择及提交/取消，避免快捷键误触发或丢字。不默认所有输入环境相同。
- [ ] **指针与数据交互**：仅对实际需要的鼠标、触控板、拖放和剪贴板路径核对操作、输入类型、取消及不可用结果；按契约反馈，不能以一种桌面或后端结果代表全部支持组合。
- [ ] **取证**：记录所选组合及理由、输入方式、尺寸和缩放、操作及预期与实际结果。截图只证明所示布局，不证明焦点、输入法或跨窗口交互；替代环境的局限和未覆盖组合须明确说明。
