# Web 前端特性

适用于浏览器运行的 Web 界面。通用界面方法由 [前端基础](../hs-dev-frontend-base/SKILL.md)提供；框架、渲染和应用路由由[Web 前端框架设计](../hs-dev-framework-frontend/SKILL.md)负责。

只读取命中本次目标的端侧资料；通用要求和验证方式见前端 Base，不重复加载。

| 当前涉及的特性 | 专有资料 |
|---|---|
| 语义元素、键盘焦点、视口适配、URL 和浏览器历史 | [browser interaction](references/browser-interaction.md) |
| 刷新、网络/会话状态、客户端存储、安全、离线或 SEO | [browser runtime](references/browser-runtime.md) |

当前平台资料用于补充平台行为；不要因为项目目标平台明确就加载表中全部资料。

先核实实际框架/组件库、浏览器支持范围、视口及输入方式和本次运行环境，再选择专题条目；涉及浏览器或工具包机制时核对适用版本的官方契约。沿用 Base 的任务与产品契约，缺失行为返回当前过程，不默认增加 SEO、离线能力或持久化。

沿用 Base 的逐项状态及证据格式，记录浏览器及版本、视口/缩放、输入方式、相关网络/会话条件、环境和操作结果。区分静态审阅、自动测试与实际浏览器行为；未执行计划标记未验证，不以单一浏览器结果外推全部支持范围。路由、缓存、渲染和安全边界与框架或后端专业入口共享证据，不重复检查或代替人工确认。
