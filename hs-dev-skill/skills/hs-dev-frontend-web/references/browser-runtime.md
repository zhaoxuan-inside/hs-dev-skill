# 浏览器运行状态与安全

只检查本次涉及的运行机制；数据、认证、缓存及渲染边界与框架/后端入口协同，不自行定义产品行为或服务端保证。

- [ ] **刷新与网络**：按契约验证重新载入、断网、请求失败、超时或恢复后界面状态与下一步；涉及取消、过期响应和重复提交时核对实际结果，不把客户端禁用按钮当作服务端幂等保证。
- [ ] **会话与用户变化**：检查适用的过期、退出或用户切换后的内容、操作和反馈，避免显示过期用户数据；前端隐藏或路由拦截不能代替服务端授权。未知认证语义交回当前过程，不擅自刷新凭据或重放有副作用请求。
- [ ] **浏览器存储**：仅持久化明确需要的数据，核对实际介质、内容、生命周期、用户隔离及清理条件；按需验证存储不可用或失效结果。敏感内容依项目安全约束和威胁边界处理，不因某种介质位于浏览器就认为安全，也不默认新增持久化。
- [ ] **安全渲染与客户端边界**：对相关 HTML、属性、URL 或富文本输出检查所用安全 API、上下文处理和必要的允许范围，不以笼统“已处理输入”证明安全；核对不可信输入不进入危险执行路径。客户端产物及配置不包含服务端秘密，相关证据不输出真实凭据。不自动扩大为全应用安全审计。
- [ ] **可选运行能力**：SEO、离线缓存和渐进增强仅在目标涉及时验证；按实际采用机制核对可见内容、缓存更新、离线反馈及恢复，不假设所有浏览器提供相同能力。
- [ ] **证据与边界**：记录初始会话、网络/存储条件、操作及预期与实际结果；模拟断网、Mock 响应和真实服务结果分开。开发服务器正常或构建成功不能证明生产浏览器行为，缺失环境时标记未验证。
