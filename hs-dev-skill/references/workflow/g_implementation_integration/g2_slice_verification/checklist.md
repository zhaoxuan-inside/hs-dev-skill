# G2 验收规则

| ID | 内部活动 | 通过标准 | 验证方式 |
|---|---|---|---|
| G2.1 | 行为验证 | 本次正常及风险相关边界/异常/不变量有适用实际验证结果，断言来自有效契约；需要 TDD 或回归保护时区分目标行为失败和修复后通过，不强制每项低影响修改新增测试或补造红阶段 | 沿切片契约和实际影响选择并执行适用用例，核对可观察结果及副作用；按需要核验缺陷前后差异，记录覆盖范围与未执行条件 |
| G2.2 | 工程检查 | 本次相关类型、静态、构建、资源或安全检查已按实际需要执行，无未解释失败；区分新增、既有、测试错误和环境故障，不以构建通过替代行为检查或擅自扩大审计范围 | 运行项目已有且与改动相关的工程检查，比较已知基线并分类失败；审阅未解释问题的影响，不删除断言或放宽标准凑通过 |
| G2.3 | 证据 | 实际检查关联对象、源版本/摘要、时间、环境、命令/操作、预期及结果，自动命令含退出码和必要输出；未执行/跳过/超时不记通过，Mock、模拟与真实边界分开，后续相关修改须复核证据 | 核对执行记录、退出结果及来源摘要，检查真实/替身范围和内容变更；计划、重跑结果和首次失败分别保留，不用旧证据冒充新修订通过 |
