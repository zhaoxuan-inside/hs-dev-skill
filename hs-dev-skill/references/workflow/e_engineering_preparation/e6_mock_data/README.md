# E6 Mock数据构建

## 目的与适用范围

为本次已选验证场景准备安全、可重复的数据。Mock 数据包含测试夹具、生成规则或模拟服务所需数据，不等于必须建立外部服务。已有数据满足用例时直接复用；无数据缺口可说明不适用，不为清单建立数据平台。

## 输入与输出

输入为有效数据/接口契约、E5 场景和实际测试约束，以及相关已有夹具/生成器。输出包含场景关联、数据或生成规则、装载方式和必要重置/清理条件，附验证结果。沿用用例标识或稳定名称，不强制新建场景编号体系及独立文件。

## 工作与核验

1. 按当前用例确定需要的数据、初态与关联，区分夹具、模拟服务数据和真实资源；不从真实环境批量复制数据填充测试，不使用真实凭据或未授权敏感内容。优先合成数据，脱敏主张须有实际依据。
2. 为适用正常、空、边界及关联场景构建最小足够样本；故意无效或畸形样本标明目标规则、预期结果和与合法契约的差异，不能要求负向样本全部通过 Schema 校验。
3. 明确数据装载、访问和正式产物边界，复用项目既有设施；测试数据不得作为正式业务兜底。合理内联的简单测试值不必迁为文件，目录隔离不自动证明运行隔离。
4. 按实际需要控制随机种子、时间、唯一标识和并行命名空间，说明关联一致性及隔离；唯一值可以变化但结果须可判断，不承诺合成样本代表真实分布或生产容量。
5. 为有状态数据说明初始化、重置或清理对象和条件，在授权隔离环境检查重复执行不会依赖历史残留；无状态夹具无需强制重置。清理仅处理本次归属资源，不自动删库或清除他人数据。
6. 用实际消费者或适用校验核对代表样本，区分合法验证、预期拒绝与环境错误；记录版本、装载/生成操作、结果及局限，按当前模式核验确认。未执行计划不冒充测试数据已验证可用。

## 边界与交接

本活动不改变业务契约、不添加正式模拟分支，也不以合成数据通过证明真实集成或生产性能。契约含义未定时返回 E1/E2，用例预期不清返回 E5；关键样本或隔离条件缺失时保持依赖阻断。适用标准及确认满足后按实际缺口转 E7、配置或实施，不自动创建服务或访问生产数据。
