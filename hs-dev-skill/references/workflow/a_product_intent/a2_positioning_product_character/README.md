# A2 定位与产品调性

## 目的与适用范围

仅在本次需要明确或调整定位、产品调性，或核验相关主张时使用。已有有效定位和品牌约束直接复用；不因进入本活动强制调研所有竞品或重做视觉系统。

## 输入与输出

输入为本次相关的问题、用户与价值结论，以及已有定位、品牌/体验约束和实际取得的替代方案资料。缺少必要上游时指出具体缺口，不预读 A1 全部历史。输出是有依据的定位、可解释的调性原则、适用边界、取舍和未决项，不要求另建品牌手册。

## 工作与核验

1. 核对当前受众、使用场景、价值和既有约束，区分已决定内容与待决定问题。
2. 只有实际定位问题需要比较时才调查竞品或替代做法，按当前问题选择有代表性的对象；记录来源、核验时间及版本/渠道等相关条件。外部事实按需查证，材料不足明确未知，不把宣传主张当作已验证效果。
3. 说明面向谁、用于什么、为何有价值及适用边界。差异化区分证据支持的事实和待验证假设；不凭竞品功能列表扩充需求。
4. 将调性落实为体验、语言、信息密度及适用审美原则，用本次场景或短例解释选择与冲突取舍；不指定无依据的组件、配色和动画规格，细节交由前端专业工作承接。
5. 按清单对账来源、定位与原则的一致性，展示结果及未决项并按当前模式处理确认。内部场景审阅不证明用户偏好或市场差异已经验证。

## 边界与交接

不在本活动安排优先级、分期、技术方案或擅自改变产品范围。阻断后续工作的定位分歧须解决或明确保持阻断；无关研究未知可以说明限制后交接，不为完成清单伪造研究。结果可更新已有材料或直接回复，满足本次适用标准和确认责任后才结束；后续按具体缺口选择活动，不自动进入详细界面设计。
