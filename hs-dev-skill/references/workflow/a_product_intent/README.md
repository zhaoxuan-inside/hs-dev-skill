# A 产品构想与宏观信息收集

## 目的与边界

明确当前产品问题、价值、定位和宏观能力边界，为后续功能设计提供依据；不在本阶段默认安排优先级、分期或技术方案。A1 明确问题与价值，A2 明确定位与调性，A3 明确能力与责任边界，按实际缺口选择，不要求局部任务全部重做。

输入来自用户目标、已有决定及可追溯的现状证据；事实、假设和建议分别记录。阶段产出复用各活动的有效结果，不额外强制生成阶段文档。通过只表示本次选定范围的适用标准和确认责任满足，不表示市场需求或用户价值已通过真实研究验证。

活动按输入依赖和影响范围连接，不按编号强制重做。
