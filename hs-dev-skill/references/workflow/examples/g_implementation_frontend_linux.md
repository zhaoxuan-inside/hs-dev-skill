# G 实现集成范例：Linux 草稿恢复

> 配套 [D Linux 架构范例](d_architecture_frontend_linux.md) 和 [E 工程契约](e_engineering_preparation_draft_sync.md)。

## 实现边界

通过所选框架获取用户数据位置；草稿写入采用实际存储提供的安全提交方式。显示协议、门户和通知放在可替换适配层，不作为保存和同步的强制依赖。关闭窗口/退出规则沿用产品决定。

## G2/G3 验证

在声明支持的发行版、桌面环境和 Wayland/X11 组合中分别检查目录权限、关闭/重启恢复、会话结束恢复和升级后数据保留。对选定包格式执行安装/升级检查；将未覆盖的环境列为未验证，不概括成 Linux 全平台通过。
