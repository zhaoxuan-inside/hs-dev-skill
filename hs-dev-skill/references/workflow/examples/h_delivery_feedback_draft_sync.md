# H 交付反馈范例：便笺离线草稿

> 虚构格式示例，不是实际交付证据。

| 验收项 | 示例状态 | 所需证据 |
|---|---|---|
| 本地保存后重启恢复 | 未验证 | 目标端步骤、运行环境和恢复内容 |
| 网络失败后安全重试 | 未验证 | 请求标识、重试结果和服务端状态 |
| 冲突时两份内容均保留 | 未验证 | 并发输入、冲突响应和用户选择记录 |

Agent 不代替开发者签署验收；未执行的检查保持未验证，测试计划不能写成通过。交接引用当前需求/契约版本、实现提交或文件位置、已执行检查、未验证平台和剩余风险。下一步示例：确认目标平台后选择对应 D/G 范例补充环境覆盖并验证。
