# G 实现集成范例：Web 离线草稿

> 配套 [D Web 架构范例](d_architecture_frontend_web.md) 和 [E 工程契约](e_engineering_preparation_draft_sync.md)。

## 实现边界

页面状态调用草稿服务；草稿服务先落本地仓库，再由同步协调器提交 API。组件不直接操作存储、不自行重试。跨标签页检测到版本变化时进入冲突状态，不能覆盖另一标签页或服务端版本。

## G2/G3 验证

| 场景 | 观察结果 |
|---|---|
| 输入后刷新 | 本地确认保存的内容恢复，状态仍区分待同步/已同步 |
| 存储写入失败 | 页面保留编辑内容，明确提示无法确认持久化 |
| 两标签页同时编辑 | 版本差异可见，原两份内容均可供选择 |
| 离线后恢复网络 | 相同 mutation ID 安全重试，服务端确认后才显示已同步 |

记录浏览器及版本、存储模式和实际操作结果；本范例列出验证方法，不声称已在任何浏览器通过。
