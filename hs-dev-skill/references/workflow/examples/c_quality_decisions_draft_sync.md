# C 质量与技术决策范例：便笺离线草稿

> 虚构案例；量化目标、技术栈和运行约束需由实际项目提供。

| 属性 | 目标表达 | 后续证据 |
|---|---|---|
| 数据持久性 | 已确认本地保存的内容应能在应用重启后恢复 | 各目标端重启场景 |
| 一致性 | 服务端冲突不静默覆盖，重复请求可安全重试 | E 契约测试、G 并发验证 |
| 可理解性 | 用户能区分本机已保存、待同步和同步完成 | 各端交互检查 |

风险包括浏览器存储限制、移动进程挂起或结束、桌面关闭窗口与退出应用语义不同，以及请求超时发生在服务端提交之后。按目标运行环境核实这些风险；不假设所有环境行为相同。

沿用仓库已有框架和部署条件。平台能力只在目标场景需要时选择；数据库、调度方式、加密、保留期限及量化 SLO 不由本例预设。
