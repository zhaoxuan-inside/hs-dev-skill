# G 实现集成范例：后端草稿同步

> 配套 [D 后端架构范例](d_architecture_backend.md) 和 [E 工程契约](e_engineering_preparation_draft_sync.md)。

## 实现边界

Handler 校验并映射协议，服务层执行 mutation 幂等和版本条件，Repository 在同一事务/一致性边界读取版本并写入新版本。过期基础版本返回冲突；存储异常不能伪装成冲突或成功。具体事务机制依项目数据库决定。

## G2/G3 验证

覆盖格式校验、相同 mutation ID 重放、两个并发旧版本写入、事务失败和身份隔离。并发场景应证明版本检查与更新不会产生静默覆盖；记录数据库类型、隔离配置和测试环境。契约测试不证明生产容量或可用性。
