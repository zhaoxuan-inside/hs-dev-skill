# G 实现集成范例：iOS 草稿恢复

> 配套 [D iOS 架构范例](d_architecture_frontend_ios.md) 和 [E 工程契约](e_engineering_preparation_draft_sync.md)。

## 实现边界

输入过程中及时写入本地仓库；视图生命周期只触发刷新和调度机会，不作为唯一保存时点。后台同步遵守实际选择的系统能力，重试保持幂等；后台不允许运行时本地内容仍可恢复。

## G2/G3 验证

验证快速输入后切后台、系统挂起/结束进程再启动、权限拒绝/撤销、软件与外接键盘、动态字体和辅助功能。记录 iOS 版本、设备、授权及后台能力；模拟器结果不自动证明真机后台调度通过。
