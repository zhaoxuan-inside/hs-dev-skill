# G 实现集成范例：Windows 草稿恢复

> 配套 [D Windows 架构范例](d_architecture_frontend_windows.md) 和 [E 工程契约](e_engineering_preparation_draft_sync.md)。

## 实现边界

窗口生命周期层把关闭/退出意图交给应用服务；应用服务确认本地写入状态后按已定产品规则处理。待同步队列存于可跨进程重启恢复的位置。若有托盘模式，关闭窗口和显式退出走不同的已批准行为；不在 UI 回调中实现同步协议。

## G2/G3 验证

验证写入尚未完成时关闭窗口、关闭后重启恢复、待同步草稿重启后续传，以及多个窗口同时编辑时的版本冲突。按目标安装方式检查数据升级保留。记录 Windows 版本、架构、包格式和用户权限；未覆盖的运行模式标记未验证。
