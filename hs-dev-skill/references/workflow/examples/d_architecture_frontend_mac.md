# D 架构设计范例：macOS 文档窗口与生命周期

> 虚构案例；共用行为和服务端契约见 [D 共用架构](d_architecture_common.md)。实现验证见 [G macOS 实现](g_implementation_frontend_mac.md)。

## 平台行为

- 草稿按文档身份关联窗口；关闭一个窗口不自动等于退出应用，也不应清除已保存的本地草稿。
- 菜单命令、键盘快捷键和窗口控件触发相同的保存/冲突业务操作，避免不同入口绕过状态检查。
- 应用进入后台或系统要求结束进程前，尽早完成已确认的本地写入；不能依赖退出回调完成唯一一次保存。
- 沙盒下的文件访问、钥匙串或通知权限只在产品确实需要时申请，并说明撤销授权后的行为。

## D4 框架边界

文档/窗口层持有当前草稿标识，应用服务管理仓库与同步；视图不直接处理沙盒授权或网络重试。具体使用系统文档模型、数据库或其他存储方案由现有技术栈和产品体验决定。

对应的菜单、窗口生命周期及沙盒验证见 [G macOS 实现范例](g_implementation_frontend_mac.md)。
