# G 实现集成范例：macOS 草稿恢复

> 配套 [D macOS 架构范例](d_architecture_frontend_mac.md) 和 [E 工程契约](e_engineering_preparation_draft_sync.md)。

## 实现边界

窗口/文档层传递稳定草稿 ID；菜单、快捷键和视图控件调用同一草稿服务。已确认内容在后台切换或系统结束进程前已写入本地仓库，不依赖退出回调承担唯一保存责任。权限和沙盒适配只由实际需要的存储能力触发。

## G2/G3 验证

分别检查关闭单个窗口、关闭最后窗口、显式退出和后台恢复；检查菜单/快捷键与窗口控件结果一致，系统结束进程后本地草稿可恢复。记录 macOS 版本、架构、沙盒和分发条件；未实测组合标为未验证。
