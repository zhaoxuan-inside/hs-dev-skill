# C1 验收规则

| ID | 内部活动 | 通过标准 | 验证方式 |
|---|---|---|---|
| C1.1 | 质量场景 | 本次适用质量目标关联需求来源及具体场景，明确对象、触发/环境、期望响应和指标或可重复审阅标准；不只写快速/安全等形容词，不强制全部质量属性 | 逐项沿业务场景核对目标来源、对象、条件、响应与判据，用示例检查能否区分满足和不满足；抽查定性标准的可重复性 |
| C1.2 | 约束权衡 | 目标的硬约束、偏好、冲突及取舍有依据，涉及资源/成本/体验的代价和必要决定明确；不默认全部最大化，不以技术偏好降低产品或已定安全要求 | 对照约束和来源审阅冲突、优先关系及代价，核对必要取舍的决定或确认依据，未决关键冲突保留阻断 |
| C1.3 | 验证方法 | 每个关键目标有可执行或可重复的验证方法、环境、样本/负载及通过条件；基线未知与待验证项明确，目标定义通过不冒充性能、安全或其他质量已达标 | 按目标检查验证步骤、样本/负载和环境是否足以判断结果，区分计划、基线测量和达标证据；可行性未知交接具体验证条件 |
