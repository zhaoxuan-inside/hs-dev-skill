# C 质量约束与技术决策

## 目的与边界

把本次质量要求、技术限制和未知转化为有依据的技术决定。C1 定义目标与判据，C2 核实约束及风险，C3 决定沿用或选择技术/方法；按实际问题和依赖选择，不把三个活动当作每次必做流水线。

复用有效产品和工程事实，区分要求、实测、假设和建议。技术取舍不能擅自改变产品行为或交付范围，不以选型代替验证。阶段通过表示本次适用决定及确认责任满足，不代表最终实现或真实运行质量达标；实验、安装、资源创建和发布仍受具体授权约束，无需额外生成阶段文档。

活动按输入依赖和影响范围连接，不按编号强制重做。
