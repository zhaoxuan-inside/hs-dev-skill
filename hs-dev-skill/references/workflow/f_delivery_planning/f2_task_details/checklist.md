# F2 验收规则

| ID | 内部活动 | 通过标准 | 验证方式 |
|---|---|---|---|
| F2.1 | 对象集合 | 当前任务目标、边界、有效输入及受影响接口/方法/数据/配置/文档/测试等适用对象可定位；区分实际与拟定对象，不为完整表格臆造符号或列入无关资源 | 对照切片及实际工程逐项审阅对象、职责和定位，核对源版本及拟定标记，检查遗漏、越界和重复任务 |
| F2.2 | 执行清单 | 当前任务有与目标关联的执行检查、可观察完成条件和可用命令/操作及必要环境；验证预期来自有效契约，简单内部方法可沿调用链覆盖，不强制逐方法独立清单或自动测试 | 按步骤演练输入到产出及验证路径，检查执行者能否判断完成；核对命令/人工操作的真实可用条件，计划与已执行结果分开 |
| F2.3 | 连续性 | 实际前置依赖、内容/证据版本及工作区安全条件已核实，未满足项保持阻断；未完成的无关任务不自动否定独立任务的规划，但任务登记和继续/恢复须遵循运行时门禁，不伪造前序完成或绕过用户决定 | 沿实际依赖和当前任务/工作区状态核对必要上游、版本及阻断，检查是否需 continuity；不能以规划独立性绕过受管门禁或覆盖已有修改 |
