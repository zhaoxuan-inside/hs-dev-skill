# 浏览器交互与布局

按本次界面和支持范围选取检查，不默认全浏览器、全设备审计。

- [ ] **语义与控件**：优先使用符合含义的 HTML 元素和原生控件；核对名称、角色、状态、表单标签及错误关系。自定义控件须有对应键盘和焦点行为，不以增加属性代替实际可操作性。
- [ ] **键盘与焦点**：检查核心路径的进入、顺序、激活、退出和可见焦点；弹层开启/关闭后的焦点位置合理，无陷阱或被遮挡的焦点。按目标需求用辅助技术验证动态反馈与阅读顺序，自动扫描不能代替操作。
- [ ] **表单与输入**：依据契约核对输入、校验、错误关联、提交中及重复操作反馈；涉及输入法、粘贴、自动填充或触控时选择相应场景。不阻断必要输入方式，不擅自增加校验规则。
- [ ] **布局与重排**：在支持范围内选择视口、缩放、长文本及字体条件，检查遮挡、截断、滚动和目标可达性；不依赖固定设备尺寸，不以缩小文字或隐藏必要内容替代适配。
- [ ] **URL 与历史**：按既定行为检查需要分享、刷新或返回的状态、前进/后退和外链；保留适用的原生链接操作，不将所有界面状态默认写入 URL。路由、直接访问和部署重写与框架入口共享验证证据。
- [ ] **取证**：记录相关浏览器、视口、缩放和输入条件，操作及预期与实际结果。截图只能证明所示呈现，不能证明键盘、表单和历史行为；未执行场景标记未验证。
