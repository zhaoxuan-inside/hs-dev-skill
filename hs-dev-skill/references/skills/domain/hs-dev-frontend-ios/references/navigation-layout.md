# iOS 导航与布局

按本次界面和支持范围选择检查，不默认增加设备、窗口或方向支持。

- [ ] **导航与呈现**：核对导航栈、返回按钮、交互返回、模态呈现与关闭后的目标及状态；按产品契约处理未保存内容。涉及手势时核对冲突、取消及过渡后的结果，不用自定义拦截破坏既定路径。
- [ ] **安全区与输入**：检查相关系统区域、键盘出现/消失及焦点切换下的内容、滚动与关键操作可达性，不重复应用安全区偏移，也不通过隐藏必要操作规避遮挡。
- [ ] **窗口与内容适配**：根据实际支持范围选择设备尺寸、方向和窗口形态；检查布局变化、长文本和内容滚动。涉及多窗口时核对界面所属窗口与呈现目标，状态所有权和生命周期由框架专项协同检查。
- [ ] **操作验证**：对受影响路径执行进入、返回、关闭及适用的交互取消，核对状态与反馈；布局变化后核心操作仍可完成。记录窗口条件、键盘状态和操作结果，截图不能证明手势、返回或焦点行为正确；无法运行时标记未验证。
