# 前端框架设计

适用于浏览器运行的 Web 前端。把已确定的交互行为、接口契约和质量目标落实为前端框架选择、应用结构及模块协作决策。若任务只涉及页面视觉、组件交互或可访问性细节，交由 [frontend base 专业入口](../hs-dev-frontend-base/SKILL.md)和[Web 端特性入口](../hs-dev-frontend-web/SKILL.md)；若涉及服务端内部结构，交由 [backend framework 专业入口](../hs-dev-framework-backend/SKILL.md)。跨端边界只读取双方共同涉及的契约。

## 设计方法

1. 确认现有框架、运行环境、部署方式、浏览器支持范围和本次质量目标；先判断现有技术是否满足约束，不因流行度更换技术栈。
2. 根据渲染方式、路由规模、数据获取、部署和团队约束比较候选框架。记录选择依据、运行代价和迁移影响；没有实际选型问题时沿用现状。
3. 按业务变化边界设计页面、功能模块、共享组件、路由和状态所有权。区分服务端状态、页面状态和跨页面状态，避免无理由的全局共享及重复缓存。
4. 描述浏览器、前端应用和服务端的调用边界，包括身份信息、请求取消、错误映射、加载与恢复状态。产品可见行为以已确认交互和接口契约为准。
5. 把性能、安全、可访问性、可测试性和部署限制映射到具体机制与验证方式；仅展开影响本次结构的属性。

## 执行检查

沿用当前过程的任务、授权及有效上游。设计形成本次需要的决定；实现落实已定契约；调试追踪实际异常链路；重构验证行为保持；评审报告问题与证据。维护任务不默认重新选型，只读任务不修改工程。

- [ ] **核实工程**：从依赖清单、锁文件、构建和部署配置确认框架及版本、应用入口、路由组织、渲染方式、浏览器支持范围和本次相关约束。区分现状、假设与建议，不把开发服务器配置当作生产部署事实。
- [ ] **选择适用项**：根据本次结构或运行问题选择设计方法及下表活动条目，复用有效决定。不因引用清单额外增加层级、全局状态、缓存、阶段文档或环境；不适用项说明理由，产品行为缺失时返回当前过程澄清。
- [ ] **核对运行机制**：涉及框架机制时核对实际版本的官方契约及工程证据。按实际模式区分浏览器、构建期及请求期服务端执行；涉及 SSR、静态生成或客户端激活时再检查其数据与状态边界。敏感配置及服务端专用依赖不能因共享模块进入浏览器产物。框架自带服务端能力属于本次边界时在此检查，后端业务服务内部设计由后端框架入口协同，不因名称含“服务端”遗漏前端运行边界。
- [ ] **验证决定**：按下表选择本次受影响的检查，记录对象、方法、环境及实际结果。可能推翻设计的未知项先在授权范围内做最小实验，或明确缺失条件；纯设计计划标记未验证，不冒充运行证据。
- [ ] **交付与停止**：逐项给出 `对象／约束与决定／状态／证据／未决项`，状态使用“通过、未通过、不适用、未验证”；说明不适用理由、失败影响和未验证条件。简单任务可直接回复，不强制新建设计文档；完成当前范围后停止，不自动换栈、扩大浏览器支持范围或部署发布。

### 验证选择

只执行本次受影响的项目；页面视觉和交互细节与前端 Base/Web 专项共享证据，不重复制定产品行为。

| 涉及项 | 验证重点 |
|---|---|
| 模块与依赖 | 对照实际导入、数据访问和调用关系检查职责及依赖方向；按需要运行已有边界检查或针对性测试，避免设计与代码脱节 |
| 路由与导航 | 按已定行为检查应用内导航、直接访问、刷新、历史前进后退及适用的错误入口；涉及部署路径或重写规则时用相应环境验证，不以开发服务器回退行为证明生产可用 |
| 状态、数据请求与缓存 | 按相关场景检查状态所有者、失效、重复请求、取消和过期响应处理；涉及身份或用户切换时检查数据隔离，不以缓存命中证明数据正确 |
| 渲染与执行边界 | 仅在实际采用时检查 SSR/静态生成/客户端激活、浏览器专用 API 及序列化边界；核对服务端与客户端初始状态及用户数据隔离，纯客户端应用不强加这些机制 |
| 构建与部署 | 检查实际生产构建、资源路径、配置注入及部署所需运行时；按需要验证目标产物或预览环境。构建成功不能代替浏览器运行验证，开发环境正常不能证明生产配置正确；检查过程不自动授权发布 |
| 质量机制 | 对照明确目标选择性能测量、安全边界或可测试性检查，记录条件和结果；界面可访问性与前端专项协同，不以采用框架或某个机制证明质量达标 |

## 产出与边界

给出本次需要的框架及结构决定、关键模块职责和依赖、影响这些决定的质量取舍，以及可验证依据。区分已验证的现状与建议方案；没有选型或结构变化时说明沿用依据。产品流程未明确时返回当前过程澄清，不自行设计交互规则。当前过程负责任务范围、执行和确认；本 Skill 不要求加载整套 C、D 或 E 阶段资料。
