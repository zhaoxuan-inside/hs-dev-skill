# macOS 窗口、文档与输入

只检查本次涉及的应用模型及操作，不默认增加文档、多窗口或工作区恢复能力。

- [ ] **窗口与文档**：按契约检查打开、切换、关闭窗口/文档与应用退出的区别；未保存内容、取消关闭及适用的窗口恢复有明确结果，不把单窗口流程强加给文档型应用。持久化及生命周期与框架 Base 协同核验。
- [ ] **命令目标**：核对受影响菜单、工具栏及快捷键作用于正确的窗口、文档或选区；启用、禁用、选中状态随上下文同步。无活动文档时按契约处理，不误操作其他窗口内容。
- [ ] **键盘与文本输入**：检查焦点进入/退出、可见焦点、键盘导航和快捷键冲突；涉及文本时验证输入法组合、提交和取消，避免触发命令或丢字。按目标系统和工具包约定工作，不无故覆盖系统常用快捷键。
- [ ] **指针与触控板**：仅对实际使用的点击、滚动、手势或拖放检查反馈、取消及边界结果，不要求所有应用实现所有输入方式。
- [ ] **验证**：记录应用及窗口/文档初始状态，执行相关打开、关闭、退出、菜单和输入路径，核对预期与实际结果。截图只证明呈现，恢复、命令路由和输入需操作证据；无法执行时标记未验证。
