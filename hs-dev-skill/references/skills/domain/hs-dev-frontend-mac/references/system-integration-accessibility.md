# macOS 系统集成与辅助功能

按实际工具包、部署目标和功能选择条目，不将所有系统能力列为必做。

- [ ] **外观与文字**：检查适用的明暗外观、对比度、文字设置及长文本下的内容与操作可用性；文字适配依据实际桌面工具包能力及项目要求，不假定与 iOS 动态字体机制相同。相关动画按目标要求处理减少动态效果。
- [ ] **辅助技术**：核对受影响控件的名称、角色、值、状态和关系；按需用 VoiceOver 验证阅读、核心操作、弹层焦点及关闭后的恢复，并检查键盘完整操作。不以语义属性存在或自动检查成功证明全部可访问。
- [ ] **授权与结果**：按实际系统能力在功能上下文中请求授权，检查适用的拒绝、受限、撤销和设置返回；界面应反映实际访问能力。说明、替代和重试方式依据产品契约，缺失时返回当前过程，不默认提权或强迫授权。
- [ ] **系统入口**：对本次涉及的 Dock、通知、分享、Quick Look、文件关联或选择器检查目标定位、输入、取消及不可用反馈；按需覆盖冷启动和已有窗口状态，不把系统面板打开视为业务完成。注册、沙箱和访问期限与框架 Base 协同核验。
- [ ] **分发环境与证据**：涉及实际包行为时核对对应环境下的用户体验；签名、公证、商店及沙箱配置由框架和当前过程处理，不自动发布或扩大权限。记录相关包环境、系统设置、授权状态和操作结果；开发启动不能证明分发包集成可用，缺失真实能力时标记未验证。
