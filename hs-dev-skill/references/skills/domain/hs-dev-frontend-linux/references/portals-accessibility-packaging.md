# Linux 门户、辅助功能与分发

只检查实际使用的能力和目标分发，系统适配、沙箱权限及安装机制与 Linux 框架专项协同，不额外增加权限或渠道。

- [ ] **能力路径**：从实际工具包和包环境核对文件选择、通知、屏幕共享或外链等能力的调用路径；按适用契约使用门户或原生适配，不假定所有能力和环境均由同一门户提供。
- [ ] **异常反馈**：对受影响能力检查成功、用户取消、拒绝、服务缺失及不可用结果；核对返回后界面和实际访问能力一致，不以面板打开证明业务成功。降级或下一步由既定产品契约决定，缺失时返回当前过程，不静默丢弃用户操作。
- [ ] **辅助功能**：对受影响控件检查名称、角色、状态和关系；按目标工具包与辅助技术实际验证阅读顺序、焦点、弹层返回和核心操作。检查适用的明暗主题、高对比度和文字缩放，不以语义属性存在或截图代替辅助技术操作证据。
- [ ] **实际分发包**：在目标包环境核对相关门户交互、文件访问、字体/主题及辅助技术连接；宿主源码启动成功不能证明沙箱包可用，不为绕过问题扩大沙箱权限。
- [ ] **证据**：记录包格式、沙箱条件、门户/桌面实现及相关版本、辅助技术和系统设置，以及操作结果。没有对应桌面或能力时标记未验证，模拟与真实环境结果分开说明，不承诺未覆盖组合通过。
