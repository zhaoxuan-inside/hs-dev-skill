# Windows 桌面集成

仅检查本次涉及的集成及实际分发环境；产品规则未明确时交回当前过程，不默认增加常驻、入口或权限。

- [ ] **关闭与退出**：按契约核对关闭窗口、退出应用、未保存内容和取消操作的结果；涉及多窗口时检查命令及提示目标。实例策略、进程退出和资源释放由框架专项协同，不能由单个窗口消失推定应用已退出。
- [ ] **系统能力与返回**：对实际使用的文件打开/保存、剪贴板、通知及协议链接检查输入、目标定位、成功、取消、不可用和权限限制后的反馈；不把面板打开或请求已发出视为业务完成。访问期限、注册和应用身份交由框架专项核验。
- [ ] **入口状态**：按需覆盖冷启动、已有窗口及需认证状态，核对目标路由和用户上下文；目标失效或输入不支持时按契约处理，不绕过访问控制或静默丢弃操作。
- [ ] **更新与分发体验**：仅在任务涉及实际渠道时检查提示、进行中、失败、重启和数据保留等已定用户体验；安装、更新、签名和商店机制由框架及当前过程处理，不将渠道特性泛化为通用 UI 要求，不自动发布。
- [ ] **证据**：记录初始窗口、登录、权限及包环境、操作和实际结果。开发启动、管理员环境或手工注册结果不能证明最终包在普通用户环境可用；无法执行的场景标记未验证，不输出签名或账号秘密。
