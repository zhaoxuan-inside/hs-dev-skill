# Windows 窗口、输入与辅助功能

按实际支持范围和本次变更选择条目，不将所有输入设备、显示器组合列为必测。

- [ ] **窗口与显示**：按既定窗口约束检查调整尺寸、最小化及恢复后的内容和操作；涉及 DPI、文字缩放或多显示器时检查跨屏、弹层位置、截断、滚动及操作可达性。窗口状态恢复与框架专项协同，不以缩小文字或隐藏必要操作替代适配。
- [ ] **键盘与焦点**：核对导航顺序、激活、退出、快捷键及可见焦点；检查弹层进入/关闭后的焦点，无无法退出或被遮挡的路径。涉及文本时验证输入法组合、提交与取消，避免误触发命令或丢字。
- [ ] **指针与其他输入**：对实际支持的鼠标、触控、触控笔路径检查目标、反馈和取消；关键功能不只依赖悬停。按项目约定选择等效操作，不要求所有功能实现所有输入方式。
- [ ] **辅助功能与外观**：核对受影响控件的名称、角色、值、状态和关系；按需用 Narrator 等目标辅助技术验证阅读顺序、核心操作和动态反馈。检查适用的主题、对比度及文字设置，不以 UI Automation 属性存在或截图证明完整可用。
- [ ] **取证**：记录窗口尺寸、显示/文字缩放、显示器及输入条件、操作与预期和实际结果。静态审阅、自动检查及真实交互分别说明，缺失目标环境时标记未验证。
