# 产出模板

用于组织面向开发者的 Markdown 结果，不定义工作流程、验收标准或新增授权。仅在当前任务需要相应文档时使用；简单结果直接回复，已有文档优先局部更新，不因加载模板创建新文件或目录。

| 模板 | 使用条件 |
|---|---|
| [设计详情](design.md) | 需要记录当前技术决定、契约、关系及验证依据 |
| [任务交接](handoff.md) | 需要跨会话或人员保留续做所需的最小上下文 |

按本次范围保留适用章节，删除填写提示、无关空表和示例图；不为填满模板虚构规则、字段、证据或恢复点。需要说明不适用或未知时记录理由，不把空白当作已完成。

内容关联实际对象、源版本及可定位的证据，优先引用唯一有效契约，不复制整份上游或历史对话。敏感信息不写入文档。模板填写完整不等于验证通过或人工确认；活动标准、确认和恢复分别遵循当前过程及对应协议。
