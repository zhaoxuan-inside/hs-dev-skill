# 执行协议

首次工程访问检查工作区安全状态。SAFE 才能获取读取凭据；在途修改等待，中断及漂移进入恢复。安全、任务完成度、验收有效性分别判断。

修改原子申请 UUID 与 fence。匹配的操作可加入，其他操作拒绝；写入前校验凭据。同 UUID 内写入仍需协调。未写入可核验后取消；已写入通过发布或恢复结束。撤销先使旧凭据失效，不能直接设安全；失联超时不等于操作完成。

任务只包含实际活动，通过 upstream 与显式产物绑定检查前置条件。A 收集宏观信息，B 提取并设计功能，F 安排交付顺序，R 对照契约评审并裁决分歧；反馈进入受影响活动。

修改前保存恢复依据，修改后真实验证，增量发布索引并核验一致性后才恢复 SAFE。读取前后检查版本，变化时丢弃结果。外部工具须在操作范围内编辑并 reconcile；绕过操作的变化需恢复处理。

验证证据绑定受管源内容摘要，发布前后复核同一摘要。验证参数在代码写入前校验；归一化路径后拒绝重复目标。先登记活动输出和确认失效，再结束提交日志；中断恢复不得遗漏已发布的变更归属。最终验证后复核已有证据与确认，失效时任务保持未完成。

验证命令受声明式门禁约束（`hs_dev_docs/foundation/gates.json`）：登记条目后，完成/提交/对账只接受 `["gate:<id>"]` 选择符，自由 argv 被拒绝；带报告（junit）的门禁在执行后解析机器测试报告，存在失败用例即验证不通过。含 E5/E9/G 活动的任务在存在报告门禁时，完成必须携带机器测试报告，不以进程退出码或自由命令充当行为证据；报告文件必须位于运行目录内，不污染受管源。

只读咨询不创建任务或业务产物，不自动修复索引。trace 是独立可选摘要记录，协调信息和 trace 不作为业务源参与索引发布。

## 受管修改与确认

受管修改先取得 UUID 与操作代次。commit 自动申请；外部编辑先 operation-start 并 snapshot，后续携带 --operation/--fence 完成 reconcile 和 operation-finish。失联所有者撤销后仍需恢复核验，不能直接宣布安全。

代码提交统一核验活动及上游依赖。reconcile 必须指定 --activity，检查实际变更符合操作范围，登记活动输出并撤销旧确认；验证期间受管源文件发生变化时拒绝发布。commit 只接受源清单和快照可覆盖的路径。上述提交是受管文件发布，不自动创建 Git commit。

任务按清单工作、真实验证并记录证据；清单标准与任务结果分别保存。mute 模型确认、activity 活动人工、stage 阶段人工；trace 是独立追踪开关。统一确认展示范围、检查摘要、交付材料与问题，日志作为支撑证据。真实确认原文不得代签，暂缓不是通过。

后续活动消费有效上游结果。验收绑定清单、内容和实际依赖；无关修改或索引重建不撤销验收。恢复准备、修改、验证、发布与核验由应用模块协调，未验证版本不能对外标为安全。

正式代码、配置、测试、Mock 数据与服务分开；外部 Mock 遵循真实协议，通过地址配置替换。无魔法业务值，不因流程扩展业务需求。

## 内核链与文档债

行为与设计的机器权威以 `:::contract` 内核块嵌在 Markdown 中：内核 JSON 非法或 ID 重复在发布时即阻断，feature → behavior → case → contract → symbol 的 ID 链在一致性门禁中对账，悬空引用等同工作区漂移处理。实现单元以 `implemented_by` 显式回填；暂无实现的行为必须给出 `unimplemented_reason`，不做未登记的实现。

文档债（`doc-debt`）是代码先于文档变化的反向失效：决策绑定的内容已变化、或行为内核的实现代码越过最近一次决策锚定即入队，未清偿的债务阻断 E9 检查、G4 提交与任务完成。豁免必须由人工以当次债务摘要落地（`doc-debt-waive`），旧豁免不覆盖新漂移；模型不得豁免文档债——要么同步文档，要么请人裁决。
