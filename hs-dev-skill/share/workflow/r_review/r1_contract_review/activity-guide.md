# R1 契约对照评审

## 目的与适用范围

对本次变更集做契约对照评审：由 diff 推导受影响的契约内核、行为、用例与决策，逐项核验实现与登记一致。评审包从登记生成，不由评审者自行圈定范围；缺登记先补登记（返回对应活动），不以口头描述替代对照物。

## 输入与输出

输入为本次变更集、受影响的契约内核与行为登记（kernel ID 链）、相关决策台账条目、用例及验证证据。输出逐项对照结论、偏离清单（缺陷或契约变更）及每项的移交对象与下一动作；结论绑定内容摘要，后续变化使其失效。

## 工作与核验

1. 用 `kernel` 命令对账 ID 链完整性；沿 `implemented_by` 从变更代码单元反查受影响行为内核，沿 object graph 补齐契约与派生文档，形成评审包。
2. 逐项比对实现与契约语义：输入/输出、错误、副作用、行为触发与前置/后置条件。发现偏离时先判定是"实现违背契约"（缺陷，交 debugging）还是"契约不再正确"（交 E1/E2 更新契约并走 G4 同步），不默认任一方正确。
3. 核对 covered_by 用例对偏离场景的可判断性：场景未被用例覆盖时登记用例缺口，不把"测试全绿"当作无偏离证据。
4. 结论进入任务材料；阻断项明确责任活动。评审通过不代替人工验收，也不解除 E9/G4 的机械门禁。

## 边界与交接

本活动不修改实现代码、不裁决取舍类分歧（交 R2）、不代替 G2/G3 的行为验证。缺陷交 debugging；契约过时交 design（E1/E2）；理解分歧交 R2。评审结论随绑定的内容摘要失效而失效，需要时重新评审受影响项。
