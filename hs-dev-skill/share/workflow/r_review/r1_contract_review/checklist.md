# R1 验收规则

| ID | 内部活动 | 通过标准 | 验证方式 |
|---|---|---|---|
| R1.1 | 评审包完整性 | 评审包由 diff 自动生成：受影响契约内核、行为、用例、决策与代码变更成套呈现；缺失对照物时先补登记再评审，不以口头描述替代 | 沿 kernel ID 链与 object graph 从变更集推导评审包，核对每项变更有所属契约或显式无覆盖说明 |
| R1.2 | 代码对照契约 | 逐项核验实现与所绑定契约的输入/输出、错误、副作用及行为一致；发现偏离登记为缺陷或契约变更，不默认代码正确也不默认文档正确 | 对每个 implemented_by 单元比对实现与契约语义，结论引用具体位置；偏离项交 debugging 或返回 E1/E2 更新契约 |
| R1.3 | 评审结论留痕 | 评审结论（通过/缺陷/契约变更建议）与依据绑定内容摘要记录；阻断项明确责任活动与下一动作 | 结论进入任务材料与决策台账；后续代码或契约变化使摘要失效时评审结论同步失效 |
