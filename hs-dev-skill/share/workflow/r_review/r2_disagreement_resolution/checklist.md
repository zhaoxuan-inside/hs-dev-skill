# R2 验收规则

| ID | 内部活动 | 通过标准 | 验证方式 |
|---|---|---|---|
| R2.1 | 分歧登记 | 对有效决策、契约或实现行为的异议以可定位对象（决策 ID/内核 ID/代码单元）登记，说明依据与期望结果；不匿名、不合并多个问题 | 每条异议绑定对象 ID 与内容摘要；重复异议合并引用，不重复登记 |
| R2.2 | 裁决路径 | 分歧按类型进入明确路径：事实分歧以证据复核，取舍分歧升级为决策记录（含被否方案），执行分歧转负责活动；不以待定状态掩盖分歧 | 核对每条异议有裁决路径与责任归属；取舍类分歧以 decision-record/supersede 落地并通知受影响方 |
| R2.3 | 结论回写 | 裁决结论回写受影响契约内核与文档，受影响确认按统一机制失效；未决异议使相关验收保持阻断 | 沿 ID 链核对回写完整性与确认失效；未决项在验收视图中保持可见 |
