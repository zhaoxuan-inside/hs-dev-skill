# G1 验收规则

| ID | 内部活动 | 通过标准 | 验证方式 |
|---|---|---|---|
| G1.1 | 契约实现 | 当前切片按有效行为、工程契约及既有兼容承诺实现，正式业务不依赖测试夹具或 Mock 兜底；不擅自删除有效兼容路径、改变产品行为或追加无关功能，必要缺口先交回负责活动 | 对照任务和有效契约审阅代表实现路径、兼容条件及模拟资源隔离，核对新行为依据与范围，相关领域技能提供专业核验 |
| G1.2 | 实际修改 | 本次实际新增、修改、删除及移动的适用代码/资源可定位且归属明确，符合任务范围和工程约定；业务常量有语义依据，不机械提取所有字面量，不覆盖用户或其他操作的修改 | 核对实际差异和对象/操作登记，检查归属、遗漏、越界及工程约定；必要时通过实际符号和调用链定位，不以计划清单代替实际修改 |
| G1.3 | 文档同步 | 受影响权威契约、代码、配置和必要派生说明一致，变更来源有效；相关针对性检查有实际证据或明确未验证条件，不以代码已写或文档已更新冒充行为及集成通过 | 对照相关权威来源、实现和派生材料检查同步，运行本次必要针对性检查并关联源版本；区分已执行、计划和后续 G2/G3 验证 |
