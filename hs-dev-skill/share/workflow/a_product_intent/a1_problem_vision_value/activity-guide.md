# A1 问题、愿景与价值

## 目的与适用范围

在当前问题、用户价值或成功预期需要明确时使用。已有有效结论直接复用，局部需求不重新发现整个产品；不要求先有完整需求文档才能开始。

## 输入与输出

输入为本次用户目标、问题描述、已有决定及相关现状证据。输出说明谁在什么情境下遇到什么问题、当前如何处理、问题影响、预期价值及成功判断；关联来源，分别记录事实、假设、设想和未知。

## 工作与核验

1. 定位本次对象和来源，先核实可从已有材料确定的信息，不反复询问有效决定。
2. 用具体场景梳理用户、当前做法和痛点；没有研究时保留用户陈述或假设的证据等级，不编造调查结论。
3. 将价值主张关联问题，区分长期愿景、本次目标与尚未确定的交付范围。没有指标基线时说明未知，不伪造数字。
4. 展示关键理解、分歧及未决问题，优先澄清会影响后续工作的决定；必要答案未到时不推进依赖动作，可继续独立分析。
5. 按清单核验结果及来源，依当前模式处理确认。文档审阅只证明本次材料的一致性，不证明市场需求或用户价值已被实证验证。

## 边界与交接

不在本活动拆详细功能、选择技术、安排优先级或承诺分期。结果可直接回复或更新已有材料，不强制新增 PRD。阻断清零且适用检查及确认满足后，按实际缺口转交后续活动；仍有阻断时交付影响及下一动作，不能宣称已准备就绪。
