# 验收

逐内部活动核对；按mute/stage/activity区分确认人，不将模型自检伪造为人工验收。

正常执行输出之外，调用[统一验收服务](../../../references/core/acceptance.md)展示进度导航、材料卡片与结果摘要。逐份列出链接和审阅重点，支持宿主勾选或明确文字回答；使用稳定材料ID与视图摘要保存决定。未通过时沟通暂缓或继续修复，保留原因和下一动作；暂缓仍阻断依赖范围。按照任务模式完成范围确认，不自行扩大授权。

先执行[主入口](../../../SKILL.md)的安全检查，按需读取[活动定义](../../../workflow/README.md)。

输出当前职责范围内的结果、证据及未决项；确认由统一模块按任务模式处理。
