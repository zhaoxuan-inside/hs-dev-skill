# 产品功能、业务规则与原型

本 Skill 属于 hs-dev-skill 的功能轴。完整包共享 scripts、references 和 resources；[运行与交接协议](../../references/subskill_contract.md)定义路径、依赖及直接调用规则。

## 职责与边界

拥有“用户要完成什么”的规则；不决定物理 DDL、SDK 或架构；No Admin 等 MVP 建议不能覆盖已确认必要功能。

## 输入

过程 Skill 的目标/阶段、开发者案例、范围、业务约束和既有产品基线。

## 执行

1. 按 DISC 还原现状、预期、范围和假设，不用推荐选项替代需求取证。
2. 先确认最小业务闭环，再写范围内规则、状态、角色与异常恢复；保持稳定 REQ/场景编号。
3. 用真实样例演练工作流程；触 UI 时由 frontend 提供专业界面表达。
4. 输出 PRD、适用的原型/Vibe Spec 与分期，逐项准备 PROD 证据。

## 输出与验收

产品规格、场景与规则、原型需求及当前基线，附 DISC/PROD 检查结果。

开发者预期需要明确确认；视觉认可不能代替业务流程认可。结果交回过程 Skill，不自行切到实现。
