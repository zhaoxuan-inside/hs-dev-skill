## 2. 双轨原型多端绘制与 UI 标注约定 (Desktop / Mobile / Web)

### 2.1 轨一：Mermaid 空间划分与交互流转拓扑
每屏至少一个清晰的 `subgraph`，表达容器包裹关系与抽屉/弹窗唤起流转，标注容器尺寸与排布方向：

```mermaid
flowchart TB
  subgraph Screen["桌面端/Web 工作台壳层 (App Shell: 1440px Max)"]
    Header["顶栏 (H: 56px)：品牌 Logo | 全局搜索 (⌘K) | 通知 | 用户工作区 [Font: 14px w500]"]
    subgraph Body["主工作区 (flex-row, H: calc(100vh - 56px))"]
      Sidebar["左侧主导航 (W: 220px, 固定)：核心业务入口 (≤5 项)"]
      MainCanvas["中央主画布 (flex-1, 滚动)：工具栏 + 数据表格 [Padding: 24px]"]
      Inspector["右侧渐进式抽屉 (W: 420px, 按需滑出)：详情与快捷编辑"]
    end
    Header --> Body
    Sidebar --- MainCanvas --- Inspector
  end
```

### 2.2 轨二：ASCII 空间比例线框与 UI 物理参数内联标注

对核心主视图及关键状态，必须绘制 **ASCII 空间比例线框图**，并在图旁或线框内清晰标注**【字体字阶】、【间距 Padding/Gap】、【容器宽度/栅格】、【对齐与微文案】**。
