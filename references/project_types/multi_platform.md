### P5 全端组合

**定义**：多端并存（Web + 移动 + 桌面 + 服务端），共享契约收敛 `packages/`，各端收敛 `apps/<client>/`。

**典型项目**：跨端 SaaS（Web 管理台 + 移动 App + 桌面客户端 + 后端）、多端协同套件。

**代码结构**：`apps/web/`、`apps/mobile/`、`apps/desktop/`、`apps/server/` + `packages/`（共享数据模型/API 契约）+ `config/`。

**影响的关键阶段**：
- 阶段 0：各端分别出原型（形态各异）+ 跨端一致体验（`DESIGN.md` 单一来源）
- 阶段 1：各端技术栈 + 跨端共享方案（Monorepo / 共享 API client）
- 阶段 2：跨端契约层（`packages/`）、端边界
- 阶段 3：共享数据模型/契约先行，各端消费
- 阶段 5：各端测试 + 跨端契约测试
- 阶段 6：各端产物分别收敛 `output/<client>/`

**专属验收维度**：

```
共享契约层（packages/）
├── [ ] 共享数据模型为唯一事实源（packages/）
├── [ ] 共享 API 客户端/契约为单一来源
├── [ ] 各端引用共享契约，无重复定义
└── [ ] 契约版本变更已同步全部消费端

跨端一致性
├── [ ] 跨端行为差异清单已落盘（如桌面快捷键 vs 移动手势）
├── [ ] 跨端登录态一致
├── [ ] 跨端数据同步一致
└── [ ] 各端产物分别收敛于 output/<client>/
```

**组合规则**：验收清单 = **P1 ∪ P2 ∪ P3 ∪ P4 各端专属验收（全量叠加）** + 上述 P5 专属项。
