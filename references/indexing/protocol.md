# 索引与上下文

索引集中于 hs-dev-skill/index/。files.jsonl 是源清单，catalog.sqlite 保存正文片段、属性、符号和依赖定位，publication.json 标识有效发布。索引是可重建派生数据。

热：当前任务原文有界常驻内存。温：正文片段进入 FTS5，SQLite 页面与查询结果有界缓存。冷：tier=cold 的正文只在磁盘，索引保存标题、属性与位置。恢复和 history 不进入模型检索。

ContextProvider 按[语义上下文协议](../context/README.md)取得安全读取凭据，解析章节和限定符号，补齐必要依赖，合并重叠区间，按完整序列化预算交付。必要集合不足则拒绝部分交付；恢复路径拒绝访问，结束时核对版本。CLI 与服务共用请求和预算，无 tokenizer 时明确标记字节保守估算。

同 Index 实例复用文件属性和已验证摘要。源改变增量更新受影响文件，未变化正文不重复切分；正常核验使用数据库文件摘要，不逐查询重建逻辑摘要。CLI 冷启动仍需枚举工程文件，常驻服务复用内存证书。索引损坏须显式 repair-index，不由读取自动修复。

服务总内存限制 200MB，含热数据、LRU、SQLite 与临时缓冲；POSIX RLIMIT_AS 提供进程地址空间硬上限。查询不等同无需核验，索引不能自行证明外部文件未修改。
