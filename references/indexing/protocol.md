# 索引与一致性

file_index.jsonl枚举源文件与摘要；content_index.jsonl记录完整范围、代次、内容锚点和源摘要。完整空索引表示无内容，未完成扫描不可发布为空。SQLite可重建，不是第二份事实源。

只有源基线未变时自动修复缺失内容索引；源漂移要求继续修复或回退。发布前后核对源，最后写索引文件和SQLite摘要的发布标记。中断不产生有效提交。

属性标签走B-tree，正文走FTS5，Python符号用AST，关系双向查询。不用LIKE回退。中文字符与双字词召回短词，查询组合可收窄；标签有规范名、别名及来源。

频繁读写的小任务对象有界常驻，不做重型索引；其他稳定内容持久索引。修改立即失效，LRU只淘汰可重建结果。服务常驻不等于模型上下文常驻。

200MB覆盖整个服务：默认SQLite约24MB、LRU48MB、任务16MB，其余运行时和查询。POSIX地址空间硬限制；非POSIX不能宣称同样保证。大型模型不载入服务。
