# 变更分级（Right-Sizing）与快路径

**何时读**：任意需求的第一步（写 PRD/编码前）；每会话最多一次。

**问题不是「单体 Skill」**，而是编排把一切需求默认当成「新产品切片」：铁律要求无条件走阶段 0 全量对齐 + 1/2/3 齐套后才允许编码，导致文案微调、单测修复、局部 bugfix 也被迫重建选型/架构/四要素，Token 与耗时陡增。

本文件定义**同 Skill 内**的分级与合法缩短路径；**不拆小 Skill**。未分级前禁止按满配 0→6 开工。

---

## 1. 分级判定（会话第一步，≤10 行落盘）

在阶段 0 写 PRD 之前，先判定 `change_size`，写入任务 brief / context_pack 首行或 PRD 元数据：

| 级别 | 判定（满足即取该级；冲突取更高） | 典型例子 |
|------|----------------------------------|----------|
| **S（快路径）** | 不改产品语义/对外契约/DB schema/限界上下文；局部代码或文案/样式/测试/配置 | 修空指针、改文案、补单测、调 CSS、修正日志 |
| **M（补丁路径）** | 改已有功能行为或内部接口，但**不**新开限界上下文、不换技术栈、不新增表族 | 加可选字段、改校验规则、补一个端点、修补偿逻辑 |
| **L（满配路径）** | 新功能/新域、换栈、新表或破坏性 API、架构边界变化、模糊 UI/新技术需对标 | 新支付域、换 ORM、公开 API 破坏性变更 |

**不确定时取 M**（不要默认 L）。用户口头说「随便改一下」若触及契约/表结构 → 升为 M/L。

---

## 2. 各路径合法阶段链

### S — 快路径（禁止空跑 1→3）

```text
分级 → 轻量对齐（记 DoD + 影响面）→ [可选] 切片装载 → 实现 + 单测 → 门禁子集 → 本地 Commit
```

| 步骤 | 要求 |
|------|------|
| 轻量对齐 | 3～8 行：改什么 / 不改什么 / DoD；**不写**完整 PRD，除非触及产品语义（则升 M/L） |
| 选型/架构/四要素 | **跳过**新建；禁止为 S 新建 ADR/架构文/四要素全套 |
| 装载 | `doc_index_db search|slice` 只取**被改文件相关**设计切片入 pack（可极短） |
| 实现 | 直接改代码；UI 则按需读 `frontend_craft.md`；不涉及 API 契约则不读 `api_engineering.md` |
| 门禁 | 相关测试 + `verify_consistency`（若未动 docs/idx 可只跑测试）；有任务则归档 |
| 询问闸门 | 仍适用；S 默认高置信推进 |

### M — 补丁路径

```text
分级 → 阶段 0 迷你 PRD（或 diff 节）→ 只补「触达面」设计 → 任务/pack → 实现 → 门禁 → Commit
```

| 步骤 | 要求 |
|------|------|
| 阶段 0 | 短 PRD 或在既有 PRD 下追加「变更节」；冻结门禁缩为：**触达面的**完整/正确/无冲突 |
| 阶段 1～2 | **跳过**除非换栈或动边界；否则引用既有 ADR/架构，只记「沿用」一行 |
| 阶段 3 | **仅更新触达的** DB/API/六元组/调用链文档与 V/U；未触达维禁止重写 |
| 阶段 4～6 | 同满配，但 context_pack 只物化触达切片 |
| API/UI | 改契约读 `api_engineering.md`；改 UI 读 `frontend_craft.md`（各每会话最多一次） |

### L — 满配路径

完整 `0 → 1 → 2 → 3 → 4 → 5 → 6`，见 [`spec_driven_lifecycle.md`](spec_driven_lifecycle.md)。模糊 UI/新技术仍先 GitHub 对标。

---

## 3. 禁止事项（防「假快路径」）

- 用 S 掩盖产品语义未决或破坏性 API/表变更。
- S/M 路径下仍整读 `spec_v2_4.md` 或整树 `hs_dev_docs`。
- 为走过场复制空 ADR/空四要素文件。
- 分级后不写 `change_size`，导致后续会话又按 L 重做。

---

## 4. 与置信度、Token 的关系

- 分级本身**不询问**（工程编排）；仅当升降级取决于产品特有空白时走询问闸门。
- Token：S 应明显少于 M，M 少于 L；若 S 会话仍加载 lifecycle 全文 + 多份 references，视为违规，改回本文件 + `token_budget.md` 挂载表。
