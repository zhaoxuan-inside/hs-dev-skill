# 执行协议

首次工程访问检查工作区安全状态。SAFE 才能获取读取凭据；在途修改等待，中断及漂移进入恢复。安全、任务完成度、验收有效性分别判断。

修改原子申请 UUID 与 fence。匹配的操作可加入，其他操作拒绝；写入前校验凭据。同 UUID 内写入仍需协调。未写入可核验后取消；已写入通过发布或恢复结束。撤销先使旧凭据失效，不能直接设安全；失联超时不等于操作完成。

任务只包含实际活动，通过 upstream 与显式产物绑定检查前置条件。A 收集宏观信息，B 提取并设计功能，F 安排交付顺序；反馈进入受影响活动。

修改前保存恢复依据，修改后真实验证，增量发布索引并核验一致性后才恢复 SAFE。读取前后检查版本，变化时丢弃结果。外部工具须在操作范围内编辑并 reconcile；绕过操作的变化需恢复处理。

只读咨询不创建任务或业务产物，不自动修复索引。trace 是独立可选摘要记录，协调信息和 trace 不作为业务源参与索引发布。
