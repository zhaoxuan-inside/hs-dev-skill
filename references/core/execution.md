# 核心执行协议

5.0.0.0。README描述定位，activity.json定义内部活动，checklist.md定义验收，任务Markdown是运行实例。活动生成源在scripts/build_docs.py，生成内容不得独立漂移。

## 进入与路径

status核验任务和一致性，未完成或漂移时用户决定继续或回退，不能开启新任务。继续复用ID，咨询确认不建任务。确定性信号先于词法召回，模型补语义，不能覆盖权限和门禁。

阶段是地图，实际路径由影响、有效依赖及风险决定。修复重构先H1读代码与行为；需求变化单独登记。无需每次重新选型或整体重写。反馈进入受影响活动，不自动扩大范围。

## 确认与证据

mute模型确认，stage阶段人工，activity逐活动人工。内部检查逐项PASS/FAIL/NA；NA有理由，PASS有证据摘要，人工确认必须来自真实会话或授权审阅。源修订、清单和证据变化使相关确认失效。


## 提交

恢复准备→登记→更新代码文档→真实验证→发布索引→失效缓存→校验→提交状态。PREPARED/VERIFIED/INTERRUPTED不可视为完成。多文件没有天然原子性，发布标记和中断恢复必须配套。

恢复覆盖所有新增删除移动和状态；普通回滚保护后续修改，整体回退须明确决定。原始索引由快照保存，恢复后以新有效代次核验四层一致，不能只恢复正文。

## 内容

A只宏观收集，B先完整功能再行为和整体关联，F安排交付优先级分期。人工文档优先Markdown表格与Mermaid，当前结论与历史讨论分开。工作集有界但不能丢必要约束。

所有管理对象有UTC时间、修订及源摘要。仅同对象、同范围、同有效状态最新有效修订优先；复制、缓存和索引时间不能覆盖权威源。并发冲突显式解决，配置按层级而非时间覆盖。
