# H 交付、验收与反馈

本阶段组织同一抽象层次的活动；通过条件为适用内部活动清单全部通过，且验收模式要求满足。

活动之间按输入依赖和影响范围连接，不按编号强制重做。

- [H1 完整性对账与现状核验](h1_coverage_review/README.md)
- [H2 交付与恢复验证](h2_delivery_recovery_verification/README.md)
- [H3 验收](h3_developer_acceptance/README.md)
- [H4 反馈与后续](h4_feedback_handoff/README.md)

验收统一调用[验收服务](../../references/core/acceptance.md)，展示进度导航、材料卡片和结果摘要。登记待审文档，支持勾选或明确回答逐份确认；未通过逐项沟通暂不处理或继续修复，记录原因及下一动作，暂缓不记通过。内部清单和模式确认仍须满足。
